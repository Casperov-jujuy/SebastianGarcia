Juego interactivo desarrollado para la campaña de Sebastian Garcia. Esta experiencia lúdica presenta a un candidato comprometido con mejorar la infraestructura local, simbolizado a través de un personaje que recorre la ciudad tapando pozos. El juego busca crear conciencia sobre los problemas de infraestructura vial de manera divertida y memorable, mientras muestra el compromiso del candidato con soluciones concretas para la comunidad."
